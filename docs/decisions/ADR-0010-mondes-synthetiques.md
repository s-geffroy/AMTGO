# ADR-0010 — Mondes synthétiques : propriétés, pas valeurs

*Statut : accepté — 2026-10-20.*

## Contexte
Les mondes A–F (prompt §56) énoncent le résultat attendu. Tester des valeurs
figées reviendrait à régler le modèle sur ses propres attentes.

## Décision (M5+)
Les tests vérifient des **propriétés qualitatives** : signe ($D>0$ dans E), ordre
(σ de A > σ de B), présence d'une famille de solution (overlay dans C), absence
d'une autre (pas d'État continu dans C, pas d'attribution ethnique de la
métropole dans D). Les paramètres des mondes sont tirés dans des plages, pas
fixés. Le territoire synthétique est placé en plein océan.
