# Runs synthétiques

Rapports générés automatiquement par la CI à chaque publication du site, à
partir de `configs/runs/*.yaml`. Données **synthétiques** ou cartographiques
publiques uniquement : aucune donnée réelle de population ou de groupe n'est
publiée ici.

Chaque rapport contient l'identité du run (empreintes du manifeste et des
sorties), la couverture des données, le régime constitutionnel et le manifeste
normatif, les contrôles multi-échelles, le statut de recommandation — et
déclare explicitement chaque couche non encore disponible.
